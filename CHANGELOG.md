# Changelog

## 1.0.0

- First release.
- Covers every operation of the BillionVerify API: single and batch verification, disposable check (POST and GET), file verification (upload, status, long polling, results download, resume), credits, webhooks, domain search, batch domain search and health check.
- Typed errors, automatic retries on 429, 500, 502 and 503, and webhook signature verification.
